# Al Dente
Want to cook pasta and need a timer? Al Dente provides an easy way to keep track of different pasta types and their cook time, and of course a timer! It is currently a work in project that I do on my freetime, but feel free to take a look.

## Description

Al Dente is a project with the aim to create a small desktop widget-like application for cooking pasta. The core features are:
- View pasta
- Set timer
- Create/Edit pasta
- Load pasta from file

## Installation
Download the latest release for your platform from the [releases](https://github.com/Pipublu/Al-Dente/releases).
There is no Linux support and intel and windows versions have not been tested.

## Development

### Setup
This section explains how to setup and run the source code.

Start by cloning the project and open terminal in project root.

Install requirements:
```
npm install
```

To run in development mode:
```
npm run start
```
To run production build:
```
npm run package
```
### Requirements

- Node.js
- npm
